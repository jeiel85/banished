# ⚔️ Ashborne: Feudal Manor (애시본: 봉건 영지 시뮬레이터)

> **"14세기 흑사병의 광풍이 지나간 자리, 폐허가 된 강변 영지 '애시본(Ashborne)'에 부임한 영주가 되어 백성들을 이끌고 번영하는 중세 성채를 건설하라."**

*Manor Lords*, *Stronghold*, *Banished*의 핵심 메커니즘을 집대성한 **무의존성(Zero-Dependency) 순수 HTML5 캔버스 중세 영지 경영 & 공성 수성 시뮬레이션 게임**입니다. 외부 이미지/오디오/라이브러리 전혀 없이, 브라우저 단 하나의 `.html` 파일로 즉시 실행됩니다.

## 🏰 주요 핵심 시스템 (Key Features)

### 1. 유기적 그리드 건설 & 4계절 기후 (Settlement & Seasons)
- **2D 아이소메트릭 다이아몬드 타일맵**: 강줄기, 울창한 산림, 채석용 석재 암반, 철광 노드, 비옥한 범람원.
- **도로망 보너스**: 비포장 흙길 및 포장 석판길 구축 시 주민 이동 속도 +60% ~ +90% 증가.
- **가구 부지 (Burgage Plot)**:
  - 주거 공간 제공 (최대 4인 거주).
  - **뒷마당 확장(Backyard Extensions)**: 텃밭(채소 생산), 닭장(달걀 공급), 염소 우리(고기 생산).
- **혹독한 4계절 기후 시스템**:
  - **🌱 봄 (Spring)**: 강 해빙, 밀밭 파종(Sowing) 시작.
  - **☀️ 여름 (Summer)**: 농작물 생육, 채집과 사냥의 번성기.
  - **🍂 가을 (Autumn)**: 대규모 곡물 수확(Harvesting), 겨울을 앞둔 장작 및 식량 총력 비축.
  - **❄️ 겨울 (Winter)**: 눈 덮인 영지, 얼어붙은 강, 농경 중단, **장작 소비 급증**. 장작이나 식량 고갈 시 동사 및 아사 발생!

### 2. 주민 직업 & 2차 가공 산업 사슬 (Production Chains)
- **목재 체인**: 벌목소(원목) ➔ 제재소(건축용 판자 & 겨울용 장작)
- **식량 사슬**: 밀밭(곡물) ➔ 풍차(밀가루) ➔ 공동 제빵소(빵)
- **방직 사슬**: 양 목장(양모) ➔ 직조 공방(방한 의복)
- **야철 & 군수 사슬**: 철광산(철광석) + 원목 ➔ 대장간(농기구 / 창 / 활)
- **식량 다양성 보너스**: 빵, 고기, 야생 베리, 채소, 달걀 등 다양한 식단이 확보될수록 민심(Approval)과 건강도가 대폭 상승합니다.

### 3. 민심, 세금, 시장 & 사회 (Approval & Taxation)
- **봉건 세율 슬라이더 (0% ~ 30%)**:
  - 매월 가구당 세금을 징수하여 영주 국고(Gold) 확충.
  - 지나친 과세는 민심 폭락을 부르며 유민 유입이 중단됩니다.
- **시장터 (Marketplace)**: 반경 내 가구들에 식량, 연료, 의류를 자동 배급.
- **목조 교회 (Church)**: 주일 미사와 신앙도 충족, 매장지 제공으로 영지 안정.
- **선술집 (Tavern)**: 주민들의 피로를 풀고 사기를 진작시켜 민심 급상승.

### 4. 민병대 징집 & 실시간 RTS 수성 전투 (Militia & Fortress Defense)
- **전시 징집 (Muster Militia)**:
  - 대장간에서 주조한 창과 활로 일반 농민들을 즉각 무장 소집.
  - **창병대 (Spear Militia)**: 높은 체력과 방어력으로 적 돌격을 저지하는 전열 보병.
  - **궁병대 (Archer Militia)**: 곡사 화살 사격. **방어 망루(Watchtower) 또는 성벽 뒤 배치 시 사거리 +80%, 공격력 +50% 고지대 특권 부여!**
- **목책 & 석조 성벽**: 침입자의 경로를 막고 우회로를 강제하는 방어선 구축.
- **주기적 적 습격 웨이브 (Threat System)**:
  - 영지가 성장할수록 접근하는 산적 무리(Bandits)와 약탈자들의 공성 침입.
  - 실시간 화살 궤적 투사체, 칼부림 교전, 피격 이펙트, 전과 보상(Loot Bounty).

### 5. Web Audio API 내장 프로시저럴 사운드
- 외부 MP3/WAV 파일 없이 코드 신시사이저로 100% 실시간 합성:
  - 도리안(Dorian) 중세 선법 기반의 아늑한 류트(Lute)/하프 핑거피킹 BGM.
  - 망치 타격음, 활 시위 발사음, 칼날 부딪힘, 침입 경보 나팔(Warhorn) 사운드 내장.

### 6. 100% 영속성 & 실시간 저장
- 건물 좌표, 일꾼 배정, 주민 개개인의 스탯, 국고 및 자원 재고, 계절 타이머, 도로망 정보가 `localStorage`에 완벽 저장/복원됩니다.

## 🕹️ 조작 가이드 (Controls)

| 조작 | 기능 |
| :--- | :--- |
| **마우스 좌클릭 + 드래그** | 캔버스 카메라 시점 이동 (Pan) |
| **W, A, S, D** 또는 **방향키** | 키보드로 카메라 이동 |
| **마우스 휠 스크롤** | 카메라 확대 / 축소 (Zoom In / Out) |
| **마우스 좌클릭** | 건물 선택, 유닛 선택, 건축 부지 지정 |
| **마우스 우클릭** | 선택된 민병대 이동 명령 / 적군 타겟 공격 지정 |
| **Spacebar (스페이스바)** | 게임 일시정지 / 재생 토글 |
| **하단 건축 탭** | 인프라, 채집, 농경, 가공, 사회, 군사 건물 건축 |
| **철거(Demolish) 모드** | 건물 및 도로 철거 (자재 50% 회수) |
| **세율(Taxes) 버튼** | 0% ~ 30% 봉건 영지 월간 세율 설정 |

## 🏗️ 건물 도감 및 요구 자원

- **흙길 (Dirt Road)**: 무료 / 이동속도 +60%
- **석판길 (Cobblestone Road)**: 석재 1 / 이동속도 +90%
- **가구 부지 (Burgage Plot)**: 목재 5, 판자 2 / 4인 주거 + 뒷마당 채원 확장 가능
- **벌목소 (Logging Camp)**: 목재 6 / 원목 벌목
- **제재소 (Sawpit)**: 목재 8 / 판자 & 장작 가공
- **채집꾼 오두막 (Forager Hut)**: 목재 4 / 베리 채집
- **사냥꾼 오두막 (Hunting Camp)**: 목재 6 / 육류 사냥
- **채석장 (Stone Quarry)**: 목재 10 / 석재 채석
- **철광산 (Iron Mine)**: 목재 12, 판자 4 / 철광석 채광
- **밀밭 (Wheat Field)**: 목재 4 / 봄 파종, 가을 곡물 수확
- **풍차 (Windmill)**: 목재 12, 판자 6 / 곡물 ➔ 밀가루 제분
- **공동 제빵소 (Communal Bakery)**: 목재 8, 석재 6 / 밀가루 + 장작 ➔ 빵
- **양 목장 (Sheep Pasture)**: 목재 8 / 양모 생산
- **직조 공방 (Weaver Workshop)**: 목재 6, 판자 3 / 양모 ➔ 방한복
- **대장간 (Blacksmith Forge)**: 목재 10, 석재 8 / 철광석 + 목재 ➔ 창, 활, 도구
- **시장터 (Marketplace)**: 목재 15 / 가구 물자 배급
- **목조 교회 (Wooden Church)**: 목재 20, 판자 10, 석재 8 / 신앙도 & 안식
- **선술집 (The Boar Tavern)**: 목재 14, 판자 6 / 맥주 서빙 및 민심 폭증
- **목책 성벽 (Palisade)**: 목재 2 / 체력 200
- **석조 성벽 (Stone Wall)**: 석재 3 / 체력 600
- **방어 망루 (Watchtower)**: 목재 10, 석재 6 / 체력 450, 궁수 사거리 1.8배
